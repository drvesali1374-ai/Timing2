## ۴. طراحی قالب Excel (§۹)

- **شیت «برگه زمان‌سنجی»** (راست‌به‌چپ، panes ثابت): بلوک اطلاعات واقعی پروژه/خط/محصول/
  ایستگاه/فعالیت/اپراتور/روش/وضعیت؛ سربرگ ستون‌ها (ردیف ۷)؛ ردیف‌های شبکه از ردیف ۸ —
  همان ترتیب buildGridRows (عنصر + زیرردیف‌های روابط موازی هر دو سمت). ستون‌های چرخه =
  چرخه‌های موجود با مقادیر فعلی (فرمت Paste: عدد یا «شروع-پایان») + ۱۰ ستون خالی برای
  چرخه‌های جدید. سلول‌های ورود: قالب متنی `@` (بازهٔ 3-9 به تاریخ تبدیل نمی‌شود)، رنگ
  سبز ملایم، حاشیهٔ نازک؛ ستون عنوان خاکستری غیرقابل‌ویرایش.
- **شیت «راهنما»**: راهنمای کوتاه فارسی — کدام سلول‌ها تکمیل شود، فرمت مقادیر،
  زیرردیف هم‌پوشانی (خالی/۰/مثبت)، ستون‌های جدید، و دو راه برگرداندن داده‌ها.
- **شیت «Metadata» (مخفی)**: نشانگر `T2_TIMING_TEMPLATE` نسخهٔ ۱ + SESSION_ID +
  START_CYCLE_NO + DATA_START_ROW + فهرست ردیف‌ها با شناسهٔ پایدار
  (elementId صاحب ردیف / relationId). نگاشت هرگز بر اساس نام نیست؛ نام تکراری یا
  جابه‌جایی سطر باعث انتساب اشتباه نمی‌شود.
- **بارگذاری**: POST فایل → اعتبارسنجی ساختار (نسخه، تعلق به همین جلسه، تطابق ترتیب
  ردیف‌ها با شناسه‌ها) → استخراج شبکهٔ داده با حذف ستون‌های خالی انتهایی (چرخهٔ خالی
  اضافه ساخته نمی‌شود) → خطاهای سلولی با محل دقیق «ردیف N (نام عنصر)، چرخهٔ M» →
  ورود به همان مسیر پیش‌نمایش/Commit موجود Paste (ALL_OR_NOTHING / SKIP_INVALID).
  **هیچ ذخیرهٔ مستقیمی وجود ندارد (§۹-۶).**
- **آفلاین**: همان ساختار با exceljs بسته‌بندی‌شده در `offline/vendor/` و بارگذاری تنبل —
  بدون هیچ درخواست اینترنتی در زمان اجرا (§۹-۸).
- **سازگاری Excel 2021**: فقط قابلیت‌های استاندارد OOXML (fill/border/numFmt/@/freeze/
  RTL/hidden sheet) — فایل تولیدی با `Microsoft Excel 2007+` تأیید شد. آزمون بازکردن
  در خود Excel 2021 در این محیط ممکن نبود (نرم‌افزار Excel در دسترس نیست) — صادقانه
  گزارش می‌شود؛ ساختار فایل استاندارد است.

## ۵. خطاهای کشف‌شده و رفع‌شده در حین بازبینی مرورگر

1. **ستون شناسهٔ Metadata روابط**: مقدار ستون ELEMENT_ID برای زیرردیف‌ها به‌اشتباه
   otherElementId بود و اعتبارسنجی ساختار به‌درستی رد می‌شد («اختلاف در ردیف ۲») →
   اصلاح به elementId صاحب ردیف (والد) — سرور و آفلاین.
2. **ترتیب اجرای آفلاین**: buildWorkbook قبل از بارگذاری تنبل exceljs اجرا می‌شد
   (`Cannot read properties of undefined (reading 'Workbook')`) → جابه‌جایی به داخل
   then(loadExcelJS).
3. **کلیک دکمهٔ قالب آفلاین**: ارجاع به تابع تعریف‌نشدهٔ downloadExcelTemplate →
   g.T2EXCEL.downloadTemplate.
4. **جهت گروه از/تا آفلاین**: `direction: ltr` هاردکد در CSS گروه، dir="rtl" عنصر را
   بازنویسی می‌کرد → حذف از CSS.

  واقعی از داخل برنامهٔ Excel (نه شبیه‌سازی) ممکن نبود.
